# 🚀 CODUM Social Tools

### Smarter X (Twitter) Management Starts Here

**CODUM Social Tools** is a Chrome extension designed to simplify X (Twitter) account management, reduce repetitive tasks, and improve productivity.

🌐 **Official Website:** https://codum.tr

### 🔗 Install CODUM Social Tools

**[➡️ Get CODUM Social Tools on Chrome Web Store](https://chromewebstore.google.com/detail/codum-social-tools/idcnaigkclmjnnnaojjoebkgmbeenfam)**

No ZIP downloads or manual installation required. Install directly from the official Chrome Web Store.

---

## ⚡ Features

- **Follow Management** — Organize following and unfollowing activities.
- **Engagement Tools** — Manage likes, reposts and bookmarks.
- **Account Cleanup** — Simplify repetitive account maintenance.
- **Autopilot** — Configure and manage automated workflows.
- **Media Tools** — Download supported media from X.
- **Customization** — Personalize your tools and interface.
- **Multilingual Interface** — Turkish and English support.
